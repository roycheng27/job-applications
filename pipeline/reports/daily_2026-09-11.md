## PDF Compilation Note

PDF compilation was attempted for all 7 resumes using `latexmk` installed via apt-get on Ubuntu (texlive). **All resumes compiled to 2 pages** instead of the expected 1 page. The master `resume_base.tex` also compiles to 2 pages in this environment.

**Root cause:** Cloud environment uses texlive on Linux; templates were designed for MacTeX on macOS. The font metrics and spacing differ slightly between distributions, causing overflow.

**Action:** 2-page PDFs were discarded (not committed). Compile locally with `MacTeX` for correct 1-page output:
```
cd applications/<field>/<folder> && /Library/TeX/texbin/latexmk -pdf resume.tex
```
