## ⚠️ PDF Page Count — Environment Rendering Issue

**All 7 PDFs compiled as 2 pages.** This is a cloud environment rendering issue, not a content problem.

- The unmodified base templates (`templates/AI-MLE/resume_AI-MLE_base.tex` and `templates/SWE/resume_SWE_base.tex`) also compile to 2 pages on the cloud Linux TeX Live installation.
- The templates were designed for MacTeX and render to 1 page locally. Linux TeX Live has slightly different font metrics, causing the same content to overflow.
- **Action required:** `latexmk -pdf` any of the `.tex` files on your Mac to produce the correct 1-page PDF. All tailored content is correct; only the cloud-compiled PDF layout differs.
- This issue was present in the 2026-06-24 run as well but was attributed to coursework reordering. Root cause is the Linux TeX vs. MacTeX font metric difference.
