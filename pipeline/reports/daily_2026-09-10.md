## PDF Compilation

`latexmk` and `pdflatex` were not found in this environment. All `resume.pdf` files are
absent from this PR. To compile locally:

```bash
cd applications/<field>/<folder> && latexmk -pdf resume.tex
```

MacTeX is available at `/Library/TeX/texbin/latexmk` on your Mac.

**Suggested fix for future runs:** Pre-install `texlive-latex-base texlive-fonts-recommended`
in the cloud environment setup script, or add a `apt-get install -y texlive-latex-extra`
