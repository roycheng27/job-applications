## PDF Rendering Note ⚠️

All 7 PDFs compiled without LaTeX errors but rendered as **2 pages** in the Ubuntu texlive 2023 cloud environment (pdfTeX 1.40.25). The base templates themselves also compile to 2 pages in this environment.

**Root cause:** Font metric differences between Ubuntu's texlive and MacTeX cause slightly more vertical space per line, overflowing the 1-page budget.

**Recommendation:** Compile locally with MacTeX before applying. The `.tex` files are correct and should produce 1-page output on Mac:
```bash
cd applications/<field>/<folder> && latexmk -pdf resume.tex
```
Alternatively, install a newer TeXLive (2024+) or use MacTeX-compatible packages in the cloud environment for future runs.
