Jane Street's ML Engineer Intern works on applying machine learning to the trading environment, which serves as a rapid-feedback platform for ML experimentation. Interns have access to a large GPU cluster (H100/H200/B200s) and work closely with full-time employees on real projects.

### Key Responsibilities
- Train and optimize ML models for financial applications using large GPU compute clusters
- Work on ML libraries and workflow optimization
- Apply ML to noisy financial data; understand differences between textbook ML and production/financial ML
- Collaborate closely with full-time employees as mentors

### Required Qualifications
- Undergraduate or PhD student
- Practical experience training an ML model
- Experience working on an ML library or optimizing an ML workflow
- Strong programming skills, especially Python
- Intellectual curiosity; collaborative spirit

### Preferred Skills & Keywords
- Python, PyTorch, JAX, ML frameworks
- ML model training, GPU training, workflow optimization
- Production ML, large-scale compute, financial/quantitative ML
- Hyperparameter tuning, model evaluation

### Notes
- No finance background required — they care about how you think and learn
- Same interview structure as SWE + one dedicated ML engineering round
