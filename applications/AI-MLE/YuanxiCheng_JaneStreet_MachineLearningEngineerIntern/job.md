## JD Snapshot

Jane Street is a quantitative trading firm that relies heavily on ML models for market-making and risk systems. The ML Engineer Intern role involves working alongside researchers and engineers to build, train, and evaluate ML models used in production trading systems. Interns are expected to contribute real code and models from day one.

**Key requirements:**
- Strong programming skills (OCaml, Python, C++ preferred)
- Background in ML model training, optimization, and evaluation
- Familiarity with ML frameworks (PyTorch, TensorFlow)
- Coursework or experience in probability, statistics, and linear algebra
- Ability to work across the full ML workflow from data prep to deployment

**Keywords:** ML model training, ML optimization, ML workflow, model evaluation, quantitative, trading systems, production ML
