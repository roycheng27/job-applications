- Optimize GPU utilization and model inference performance
- Develop tooling for experiment tracking, model versioning, and deployment (MLflow or similar)
- Support model evaluation and monitoring frameworks

**Qualifications:**
- BS student in CS, Statistics, or related field; graduating spring/fall 2027
- Strong Python skills; experience with PyTorch or TensorFlow
- Familiarity with cloud platforms (AWS, GCP) and ML lifecycle tools
- Experience with model training, fine-tuning, or deployment a plus

**Keywords:** ML training infrastructure, model inference, PyTorch, GPU computing, model deployment, MLflow, TensorFlow, AWS, GCP
