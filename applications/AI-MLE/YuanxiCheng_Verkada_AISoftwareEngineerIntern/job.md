## Job Description Summary

Verkada is a physical security company offering cloud-managed hardware and software products including cameras, access control, environmental sensors, and alarms. The AI Software Engineer Intern role sits on the AI/ML team working on computer vision and machine learning systems that power Verkada's product suite. Interns contribute to the full development lifecycle: training pipelines, model inference, product feature prototyping, and integration with Verkada's cloud backend.

## Key Responsibilities

- Develop and improve ML models for computer vision tasks (object detection, classification, tracking)
- Work on AI inference pipelines running at scale on embedded hardware and cloud
- Collaborate with firmware, backend, and product teams to ship AI features
- Prototype and evaluate new model architectures and techniques
- Write clean, production-quality Python and potentially C++

## Qualifications

**Required:**
- Pursuing BS/MS in CS, EE, Statistics, or related field
- Strong Python skills; familiarity with ML frameworks (PyTorch, TensorFlow)
- Understanding of ML fundamentals: model training, evaluation, optimization
- Experience with computer vision or deep learning projects

**Preferred:**
- Experience with CNNs, object detection (YOLO, RCNN family), image segmentation
- Familiarity with model deployment and inference optimization
- Prior internship or research experience in ML/CV
