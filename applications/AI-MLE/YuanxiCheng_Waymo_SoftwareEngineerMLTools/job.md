## Job Description Summary

Waymo, Alphabet's autonomous driving subsidiary, is hiring new-grad Software Engineers for their ML Tools team. This team builds the internal infrastructure and tooling that Waymo's ML researchers and engineers use to train, evaluate, and deploy models powering the Waymo Driver. The role focuses on developer productivity, ML pipeline tooling, data pipelines, experiment tracking, and the systems that enable ML research at scale.

## Key Responsibilities

- Design and build internal ML tooling and infrastructure used across Waymo's ML org
- Develop data pipelines, training orchestration, experiment management, and evaluation frameworks
- Collaborate closely with ML researchers and engineers as an internal platform team
- Improve developer velocity for teams training and iterating on autonomous driving models
- Write high-quality Python (and potentially Go/C++) for production ML systems

## Qualifications

**Required:**
- BS/MS/PhD in CS, EE, or related field (new grad)
- Strong software engineering fundamentals (data structures, algorithms, system design)
- Python proficiency; experience with ML frameworks (PyTorch or TensorFlow)
- Experience building reliable, scalable software systems

**Preferred:**
- Experience with ML infrastructure, data pipelines, or MLOps tooling
- Familiarity with distributed systems, experiment tracking, or training orchestration
- Prior work on ML tooling, developer tooling, or internal platform engineering
