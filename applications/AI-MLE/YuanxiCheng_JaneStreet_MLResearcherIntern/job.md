## Job Description Snapshot

Jane Street is a quantitative trading firm and liquidity provider. The ML Researcher Intern role focuses on researching and implementing machine learning models applied to financial data and trading systems. Interns work alongside researchers on real production problems.

**Key responsibilities:**
- Research, design, and evaluate ML models for trading and risk applications
- Work with large-scale financial datasets using Python and statistical tools
- Implement and validate model changes with rigorous evaluation frameworks
- Collaborate with researchers to iterate on model architectures and hyperparameters

**Requirements:**
- Strong mathematical and statistical background
- Proficiency in Python; experience with PyTorch, NumPy, scikit-learn
- Familiarity with ML model evaluation, hyperparameter tuning
- Data structures and algorithms knowledge
- Graduating 2025–2027
