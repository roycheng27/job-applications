## Job Description Summary

Tesla's AI Inference team develops the compiler and runtime stack that deploys neural networks on Tesla's custom Dojo and FSD hardware. This internship is focused on building and optimizing the software layer between ML models and massively-parallel inference hardware.

**Responsibilities:**
- Develop compiler passes and runtime optimizations for neural network inference on custom silicon
- Profile and benchmark inference workloads to identify bottlenecks
- Implement low-level performance improvements across the AI inference stack
- Collaborate with hardware and ML teams on end-to-end model deployment

**Requirements / Preferred Qualifications:**
- Pursuing BS/MS in Computer Science, Electrical Engineering, or related field
- Strong C++ programming skills (primary language for compiler/runtime work)
- Understanding of compilers, computer architecture, or GPU programming
- Experience with deep learning frameworks (PyTorch, TensorFlow)
- Familiarity with neural network architectures and inference optimization
- Knowledge of LLVM, MLIR, or similar compiler infrastructure is a plus
