## Job Description Snapshot

Microsoft's AI Platform team builds infrastructure and tooling for LLM training, fine-tuning, and inference at scale. SWE Interns in this org contribute to real shipped features in Azure AI, Copilot, or internal ML platform tooling.

**Key responsibilities:**
- Design and implement features for ML model serving and LLM inference pipelines
- Build data processing and retrieval systems that scale to billions of documents
- Work across the stack: Python backend, cloud infrastructure (Azure/AWS), vector DBs
- Collaborate with researchers and PMs to ship AI-powered product features

**Requirements:**
- Proficiency in Python; experience with PyTorch or TensorFlow
- Understanding of LLM inference, embeddings, and retrieval systems
- Familiarity with cloud platforms (Azure, AWS, GCP)
- Strong CS fundamentals (data structures, algorithms, systems)
- Graduating 2025–2027
