## Job Description Snapshot

ByteDance's ML infrastructure team builds and maintains production ML systems that power recommendation, search, and content understanding at scale. The Applied ML Production Engineer Intern bridges research and production, ensuring ML models run reliably at ByteDance's scale.

**Key responsibilities:**
- Design and maintain scalable ML data and training pipelines in Python and C++
- Work on model serving infrastructure: latency, throughput, and reliability
- Debug and optimize production ML jobs; instrument monitoring and alerting
- Collaborate with ML researchers to productionize new model architectures

**Requirements:**
- Strong Python and C++ programming skills
- Experience with ML frameworks: PyTorch, TensorFlow
- Familiarity with distributed systems and MLOps tooling (MLflow, Vertex AI)
- Understanding of data pipeline design and reliability engineering
- Graduating 2025–2027
