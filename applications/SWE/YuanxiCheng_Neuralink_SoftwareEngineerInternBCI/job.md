## JD Snapshot

Neuralink is developing a fully implantable brain-computer interface (BCI) to help people with paralysis control computers and communication devices. The BCI Applications team builds the user-facing software that decodes neural signals and translates them into real-time actions on external devices.

**Responsibilities:**
- Build and iterate on user-facing BCI applications that decode neural signals in real time
- Develop algorithms for neural signal processing and real-time inference
- Write production Python and TypeScript/JavaScript code for BCI interaction software
- Work with a small, fast-moving team shipping software directly used by clinical trial participants
- Potentially work with Swift for iOS/macOS BCI app interfaces

**Requirements / Preferred:**
- Proficiency in Python and TypeScript/JavaScript (Swift a plus)
- Experience with real-time systems, low-latency software, or signal processing
- Background in biomedical engineering, neuroscience, or related field a plus
- Strong algorithmic reasoning; neural network/ML familiarity helpful
- BS/MS in CS, Biomedical Engineering, Electrical Engineering, or related; graduating 2027+

**Keywords:** Python, TypeScript, JavaScript, real-time inference, low-latency, user-facing software, algorithm development, BCI, biomedical, neural signal processing
