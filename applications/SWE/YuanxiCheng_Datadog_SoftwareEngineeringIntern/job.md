## Job Description Snapshot

Datadog is the cloud monitoring and observability platform used by thousands of engineering teams. The SWE Intern role works on core product teams building scalable, distributed systems.

**Key responsibilities:**
- Design and implement features for Datadog's monitoring, APM, or infrastructure products
- Work on high-scale distributed backend systems handling millions of events per second
- Write production-quality code in Go, Python, or Java
- Partner with senior engineers on system design and architecture

**Qualifications:**
- BS student graduating spring 2027
- Strong CS fundamentals: data structures, algorithms, distributed systems
- Experience with cloud platforms (AWS, GCP) and containerization a plus
- Backend or systems engineering background preferred

**Keywords:** distributed systems, cloud-native, observability, backend engineering, AWS, GCP, Kubernetes, Python, Go
