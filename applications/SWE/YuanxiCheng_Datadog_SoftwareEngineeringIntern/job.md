## Job Description Summary

Datadog is a cloud monitoring and observability platform used by thousands of engineering organizations. The Software Engineering Intern role is placed on one of Datadog's product engineering or infrastructure teams, contributing to features across APM, logs, metrics, dashboards, or internal platform systems. Interns work in Go, Python, or Java depending on team placement, receive real ownership of a project, and engage with Datadog's engineering culture directly.

## Key Responsibilities

- Build new features or improve existing functionality within Datadog's observability product
- Write high-quality, tested code in Go, Python, or Java
- Work with distributed systems, time-series data, or observability infrastructure
- Participate in code reviews, design discussions, and engineering sprints
- Ship a complete intern project with measurable product or performance impact

## Qualifications

**Required:**
- Pursuing BS/MS in CS or related field
- Strong programming fundamentals and proficiency in at least one backend language
- Understanding of data structures, algorithms, and software design principles
- Ability to work independently on an ambiguous problem

**Preferred:**
- Experience with distributed systems, monitoring, or observability tooling
- Backend or infrastructure project experience
- Familiarity with Python, Go, or Java; experience with databases or cloud services
