## Job Description Snapshot

Datadog is a cloud monitoring and observability platform. SWE interns contribute to core agent, backend services, or data pipeline infrastructure powering real-time telemetry ingestion and alerting at massive scale.

**Key Responsibilities:**
- Develop features and improvements on Datadog's backend or data infrastructure
- Work with high-throughput distributed systems processing billions of events per day
- Write production-quality Go, Python, or Java code with proper testing
- Collaborate with senior engineers on system design and architecture

**Requirements:**
- Pursuing CS or related degree; off-season availability
- Strong fundamentals in distributed systems, data structures, algorithms
- Python, Go, Java, or C++ proficiency
- Familiarity with cloud environments (AWS, GCP, Azure)
