## Job Description Summary

Amazon Web Services (AWS) Data Services team builds distributed data infrastructure and services used by millions of customers globally, including products like Amazon Redshift, AWS Glue, Amazon Athena, and DynamoDB. The SDE Intern role is embedded on a product/engineering team contributing to the design and implementation of large-scale data processing systems and cloud services. Interns own a defined project from design through implementation and code review.

## Key Responsibilities

- Design, implement, test, and deliver software for large-scale distributed data systems
- Write production Java and/or Python code following Amazon's engineering standards
- Work with senior engineers, receive mentorship, and participate in code reviews
- Own a scoped intern project end-to-end, presenting results at end of summer
- Collaborate across teams in a highly distributed engineering organization
