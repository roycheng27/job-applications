## Job Description Summary

Rippling is a workforce management platform that automates HR, IT, and finance operations for companies of all sizes. The Software Engineer Intern role is embedded on one of Rippling's product engineering teams (payroll, benefits, IT, spend, or platform), building features and backend systems in Python. Rippling moves fast; interns are given real ownership of projects and are expected to ship production code by the end of their internship.

## Key Responsibilities

- Build product features or backend services in Python across Rippling's product suite
- Work on data models, APIs, and business logic for HR/IT/finance automation
- Write clean, well-tested code and participate in code and design reviews
- Collaborate with product managers, designers, and senior engineers
- Own an intern project end-to-end with production impact
