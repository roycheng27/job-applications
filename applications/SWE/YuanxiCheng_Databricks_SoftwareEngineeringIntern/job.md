## Job Description Snapshot

Databricks builds the Data + AI platform used by thousands of companies for large-scale data engineering, ML, and analytics. Engineering interns work across the Lakehouse platform (Delta Lake, MLflow, Unity Catalog, Spark) on problems at petabyte scale.

**Typical requirements:**
- Pursuing a BS/MS in CS or related field
- Strong software engineering fundamentals (algorithms, distributed systems concepts)
- Experience with Python, Java, or Scala; data engineering background a plus
- Familiarity with cloud platforms (AWS, GCP, Azure) and distributed data tooling

**What interns do:**
- Build features in the Databricks platform (query engine, Unity Catalog, MLflow, etc.)
- Write production-quality code with testing and code review
- Work closely with full-time engineers on 12-week projects
