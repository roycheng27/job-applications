## Job Description Snapshot

Google's SWE Intern program places interns on product teams building large-scale distributed systems, infrastructure, and AI-powered products. Interns own a defined project with a host engineer mentor and deliver production-quality code.

**Key responsibilities:**
- Design, implement, and test software features within a product team
- Work with large-scale data processing, infrastructure, or ML systems
- Write clean, well-tested code in Python, C++, or Java
- Contribute to code reviews and engineering design discussions

**Requirements:**
- Strong CS fundamentals: data structures, algorithms, systems
- Proficiency in at least one of Python, C++, Java
- Experience building software at scale (data pipelines, distributed systems, or ML backends)
- Graduating 2025–2027
