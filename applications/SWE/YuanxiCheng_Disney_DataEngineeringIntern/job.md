## Job Description (Confirmed via WebSearch / disneycareers.com)

Disney's Data Engineering Intern role sits within the Commerce Data Platforms team. The intern will contribute to building and maintaining large-scale data pipelines that power Disney's commerce and analytics infrastructure. Compensation: ~$43/hr.

### Key Responsibilities
- Build and maintain ETL/ELT data pipelines using Python, Spark, and Airflow
- Work with Delta Lake and Databricks for data lakehouse architecture
- Develop and optimize SQL queries across Snowflake and BigQuery
- Collaborate with analytics and data science teams to deliver reliable data products
- Monitor pipeline health and implement data quality checks

### Qualifications
- Pursuing a BS/MS in Computer Science, Data Engineering, or related field
- Strong SQL skills; experience with Snowflake or BigQuery preferred
- Python proficiency; familiarity with Scala or PySpark a plus
- Experience with workflow orchestration tools (Airflow, dbt)
- Understanding of distributed data systems and cloud platforms (AWS, GCP)

### Preferred Skills
- Databricks, Delta Lake, or similar lakehouse platforms
- Experience building production data pipelines
- Knowledge of data modeling and schema design
