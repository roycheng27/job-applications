## JD Snapshot

Palantir's Forward Deployed Software Engineer (FDSE) Intern role is a client-facing engineering position. FDSEs work directly with clients to understand their data problems and build custom software solutions using Palantir's platform (Foundry, AIP). The role blends software engineering with data analysis and client consulting — interns are expected to ship working software in production within weeks.

**Key responsibilities:**
- Deploy and customize Palantir Foundry/AIP pipelines for client use cases
- Analyze large, messy real-world datasets to uncover actionable insights
- Build dashboards and data visualizations for client stakeholders
- Write production-grade code and collaborate with client teams on integration

**Key qualifications (from job posting):**
- CS, Statistics, Math, or related BS degree in progress
- Strong programming skills (Python or Java preferred)
- Comfort with data analysis: SQL, pandas, data wrangling
- Analytical mindset; ability to present findings to non-technical stakeholders
- No specific experience with Palantir tools required

**Keywords matched:** pandas, Tableau, data analysis, client deployment, BigQuery, SQL, Python
