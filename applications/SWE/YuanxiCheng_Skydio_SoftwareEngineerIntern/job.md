## Job Description Summary

Skydio builds AI-powered autonomous drones for enterprise, public safety, and defense. The SWE Intern role involves backend software development — building REST APIs, cloud infrastructure (GCP), data pipelines, and services that connect Skydio's drone fleet to its cloud platform. Python is the primary language; relational databases and cloud services are used extensively.

## Key Qualifications / Keywords

- Python (primary language)
- Cloud infrastructure: GCP (Pub/Sub, Cloud Storage, BigQuery)
- REST APIs and backend microservices
- Relational databases (PostgreSQL / BigQuery)
- RAG pipeline / data pipeline development
- Time-series data and telemetry processing
- Strong software engineering fundamentals
