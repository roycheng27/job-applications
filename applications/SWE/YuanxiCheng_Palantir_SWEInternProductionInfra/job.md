## Job Description Snapshot

Palantir's Production Infrastructure team owns the reliability, scalability, and observability of Palantir's deployed platforms (Foundry, Gotham, Apollo). Interns build production systems that handle real customer data and must meet strict reliability SLAs.

**Key responsibilities:**
- Build and maintain production infrastructure components in Python and C++
- Work on distributed systems: service reliability, deployments, monitoring, and incident response
- Design and implement tools that improve system observability and developer velocity
- Ship production-quality code on tight timelines with minimal oversight

**Requirements:**
- Strong systems programming skills: C++, Python
- Understanding of distributed systems concepts (reliability, consistency, fault tolerance)
- Experience with production software: testing, monitoring, CI/CD
- High ownership mentality; comfort shipping real features to production
- Graduating 2025–2027
