## Job Description Summary

Tesla's Service Engineering team builds the software systems that support Tesla's global service and vehicle maintenance operations. This includes diagnostic tooling, service workflow automation, vehicle data pipelines, and internal tools used by Tesla service technicians and engineers worldwide. The intern role contributes to one of these product areas, writing Python or Java for backend services and internal tooling.

## Key Responsibilities

- Develop backend services or internal tooling for Tesla's service operations
- Work with vehicle data, service records, and operational workflows
- Build features that improve efficiency for Tesla service technicians globally
- Write clean, maintainable code with tests; participate in engineering reviews
- Own a defined intern project from design through delivery
