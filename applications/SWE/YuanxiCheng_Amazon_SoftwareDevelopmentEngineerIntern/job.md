## Job Description Snapshot

Amazon's SDE Intern program places students across AWS, Retail, Alexa, Advertising, and other org units. Interns own a self-contained project end-to-end, from design doc through code review and deployment.

**Typical requirements:**
- Pursuing a BS in CS, CE, or related field (not yet graduated at time of internship)
- Proficiency in at least one OOP language (Java, C++, Python)
- Strong data structures and algorithms foundation (interview focus)
- Experience with distributed systems or cloud services a plus

**What interns do:**
- Author a design document and implement a feature end-to-end
- Work with a mentor SDE and present a final project demo
- Participate in code reviews and on-call rotations where applicable
