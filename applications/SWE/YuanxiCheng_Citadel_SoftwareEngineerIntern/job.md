## JD Snapshot

Citadel is a leading global hedge fund and financial services firm. The SWE internship sits on product/platform teams building trading infrastructure, risk systems, portfolio analytics tools, and ML/NLP pipelines used by portfolio managers and analysts.

**Responsibilities:**
- Build scalable, high-performance software for trading, risk, and analytics platforms
- Develop ML and NLP solutions integrated into production financial systems
- Work on distributed computing and data pipelines supporting real-time decision-making
- Collaborate with quants and researchers to productionize models

**Requirements / Preferred:**
- Strong knowledge of data structures and algorithms
- Proficiency in Python, C++, or Java
- Experience with machine learning, NLP, or distributed systems a plus
- BS/MS/PhD in CS, Math, Physics, Statistics, or related; graduating 2027+
- Demonstrated ability to write clean, efficient code

**Keywords:** Python, C++, distributed computing, ML, NLP, data structures, algorithms, financial systems, scalable software, real-time
