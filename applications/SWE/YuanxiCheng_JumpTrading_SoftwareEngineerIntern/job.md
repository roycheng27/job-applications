## JD Snapshot

Jump Trading is a research-driven quantitative trading firm. SWE interns build high-performance, low-latency infrastructure and tools that power trading systems and research workflows. Engineering at Jump is deeply technical and operates at the intersection of software performance and financial systems.

**Responsibilities:**
- Build and optimize low-latency systems and infrastructure for trading operations
- Develop tools that support quantitative research and strategy development
- Write production-quality C++ and Python code in performance-critical environments
- Contribute to distributed systems and data pipelines at scale

**Requirements / Preferred:**
- Strong proficiency in C++ and/or Python
- Solid CS fundamentals: data structures, algorithms, operating systems
- Understanding of distributed systems, networking, or systems programming
- Interest in quantitative finance or high-frequency trading systems
- BS/MS in CS, Math, Statistics, Physics, or related; graduating 2027+

**Keywords:** C++, Python, algorithms, data structures, high-performance, low-latency, distributed systems, numerical computing, quantitative finance
