## Job Description (sourced from README listing)

Google's STEP / Software Engineer Intern program places interns on product teams across
Search, Maps, YouTube, Cloud, and other core infrastructure. Interns work on real projects
with a host engineer, contributing production code in C++ or Java (or Python/Go depending
on team). Strong CS fundamentals and algorithmic problem-solving skills are the primary bar.

**Key Requirements:**
- Strong data structures and algorithms knowledge
- Proficiency in C++, Java, or Python
- Experience with systems-level programming preferred
- Collaborative, cross-functional team environment
- Currently pursuing BS/MS in CS or related field

**Qualifications Match:**
- C++/Java: in Languages (promoted to front for this role)
- Systems/pipelines: Capital One 6-stage Python pipeline with FAISS, rate limiting, backoff
- Large-scale data: Kohl's 8.5M+ records BigQuery, custom data pipeline
- Custom tooling: Capital One LLM client with token rate limiting
- GCP ecosystem: promoted in Tools
