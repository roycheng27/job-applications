## JD Snapshot

Palantir builds data platforms (Foundry, AIP, Gotham) that help governments and enterprises integrate and analyze massive datasets. SWE interns contribute to the core platform, working on data pipelines, ontology layers, and UI/backend features. Palantir values engineers who can reason about complex systems and communicate directly with users (forward-deployed engineer culture).

**Key requirements:**
- Strong programming skills in Python, Java, or Go
- Experience building data pipelines or working with large-scale datasets
- Familiarity with data warehousing tools (BigQuery, Snowflake) a plus
- Ability to work closely with customers and explain technical decisions
- Self-directed; comfortable in ambiguous, fast-paced environment

**Keywords:** BigQuery, Snowflake, data platform, pipeline, ontology, enterprise software, data integration
